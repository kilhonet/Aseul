## 概述

Claude 和 Codex 都有 5 小时限额和每周限额。你可能遇到过工作正起劲时撞上限额被迫停下,或者为了看看用了多少而专门去打开用量页面。

Aseul 在任务栏时钟旁边显示一个**小小的圆形仪表**。每个服务一个圆:外环是每周用量,内环是 5 小时用量。圆环按用量从 12 点方向顺时针填充,颜色越接近红色,离限额就越近。还剩多少,扫一眼就知道。

点击仪表会打开状态窗口,可以看到准确的用量、距离下次重置的剩余时间以及过去 7 天的使用记录。关闭窗口后,仪表仍留在任务栏上并持续更新。

## 主要功能

- **任务栏圆形仪表** — 每个服务一个双环(外 = 每周,内 = 5 小时)。左边的圆是 Claude,右边的圆是 Codex。
- **五级颜色** — 圆环每 20 % 分为一段,依次为绿 · 黄绿 · 黄 · 橙 · 红。空的段也以淡色显示,随时能看到剩下的段是什么颜色。
- **自动刷新** — 定期检查 Claude 和 Codex 的用量,保持最新。
- **悬停即见数字** — 鼠标悬停在仪表上,每个服务显示一行,如 `Claude : 5% / 50%`(5 小时 / 每周)。
- **状态窗口** — 各服务的 5 小时 · 每周用量条以及距离各自重置的剩余时间。
- **7 天使用记录** — 每天一根柱子,显示每周用量和当天用了多少。
- **适配任务栏主题** — 浅色任务栏上仪表背后会铺一块黑色 LED 面板,深色任务栏上只显示圆环。切换主题后立即生效。
- **只显示在用的服务** — 只为已登录的服务画圆。只用 Codex 的话,就只有 Codex 一个圆。
- **开机时运行** — 在右键菜单中开启或关闭。安装版在安装时开启。
- **22 种语言** — 跟随 Windows 显示语言。

## 使用方法

### 开始使用

1. 确认已登录 **Claude Code** 或 **Codex**。Aseul 通过这个登录读取用量(参见下方"系统要求")。
2. 运行 Aseul。稍等片刻,任务栏通知区域左侧会出现**圆形仪表**。
3. 查看仪表。外环是每周用量,内环是 5 小时用量。圆环越满、越接近红色,剩下的就越少。
4. 想看准确数字,可以把**鼠标悬停**在仪表上,或**点击**仪表打开状态窗口。
5. 用关闭按钮或 **Esc** 关闭状态窗口。仪表会保留并继续更新。

### 常见情况

**交给它一个大任务之前,先看看还剩多少**
鼠标悬停在仪表上,立刻能看到 5 小时 / 每周用量,如 `Claude : 35% / 72%`。如果每周用量快到红色段,可以把大任务安排到重置之后。

**想知道限额什么时候恢复**
点击仪表打开状态窗口。5小时 · 每周用量条右侧会显示剩余时间,如 **2天21小时后重置**。

**想看这周哪天用得最多**
在状态窗口中把鼠标悬停在某个服务(Claude 或 Codex)上,就会显示过去 7 天的图表。每天一根柱子,最右边是今天。柱子高度是当天的每周用量,顶部颜色较深的部分是当天增加的量。鼠标悬停在柱子上会显示日期、每周用量和当天的增量,如 `10/15(周四) · 56% (+12%)`。

**只用 Claude 或只用 Codex**
无需任何设置。只有已登录的服务会在仪表上画圆,状态窗口里也只显示该服务。

**使用浅色任务栏时**
仪表背后会铺一块黑色 LED 面板,让圆环颜色清晰可见。切换到深色后面板消失,只剩圆环。切换任务栏主题后立即生效。

**更改了任务栏大小时**
使用小任务栏按钮或两行任务栏等导致高度变化时,仪表会立即重新适配。圆的大小与托盘图标相同,在高 DPI 显示器上也很清晰。

**每次开机都显示仪表**
右键单击仪表 → 勾选 **开机时运行**。安装版在安装时已开启。再点一次即可关闭。

**重新登录 Claude Code 或 Codex 之后**
Aseul 这边无需任何操作。下次检查时会读取新值,仪表继续工作。在此之前,状态窗口会以淡色显示最后收到的值。

**在登录之前运行了 Aseul**
如果 Claude Code 和 Codex 都没有登录,Aseul 会提示"没有已登录的 AI。"后退出。登录其中任意一个后再运行即可。

**再次找到状态窗口**
状态窗口不会在任务栏上创建自己的按钮。点击仪表时,它会在仪表所在显示器的中央打开;如果已经打开,则会移到最前面。再次运行 Aseul 也不会启动第二个,而是打开状态窗口。

**完全退出 Aseul**
右键单击仪表 → **退出** → **是**。只关闭状态窗口并不会退出,仪表会保留。

## 设置

没有设置窗口。唯一可改的是右键菜单中的 **开机时运行**,其他都自动跟随系统。

| 项目 | 跟随 |
|---|---|
| 开机时运行 | 安装版开启,免安装版关闭 — 在右键菜单中更改 |
| 显示的服务 | 已登录的服务(Claude、Codex) |
| 仪表外观 | 任务栏的浅色 / 深色主题 |
| 仪表大小 | 托盘图标大小(任务栏缩放) |
| 状态窗口 | 始终为深色 |
| 界面语言 | Windows 显示语言(22 种语言,其他为英语) |

## 系统要求

- Windows 10 · Windows 11 (64 位)
- 需要登录 **Claude Code** 或 **Codex**。

## 概要

Claude と Codex には 5 時間の上限と週間の上限があります。作業の真っ最中に上限に達して止まってしまったり、どれくらい使ったかを見るためだけに使用量のページを開いたりしたことがあるでしょう。

Aseul はタスクバーの時計の横に**小さな円形ゲージ**を表示します。サービスごとに円がひとつ、外側のリングが週間使用率、内側のリングが 5 時間使用率です。リングは使った分だけ 12 時の方向から時計回りに満ちていき、緑から赤に近づくほど上限が近いことを示します。ギリギリかどうかは、ちらっと見るだけでわかります。

ゲージをクリックするとステータス画面が開き、正確な使用率、次のリセットまでの残り時間、過去 7 日間の使用記録を確認できます。画面を閉じてもゲージはタスクバーに残り、更新を続けます。

## 主な機能

- **タスクバーの円形ゲージ** — サービスごとに二重リング(外側 = 週間、内側 = 5 時間)。左の円が Claude、右の円が Codex です。
- **5 段階の色** — リングを 20 % ずつ 5 区間に分け、緑 · 黄緑 · 黄 · オレンジ · 赤で塗り分けます。空の区間も薄い色で表示されるので、残りの区間が何色かいつでもわかります。
- **自動更新** — Claude と Codex の使用率を定期的に確認し、最新の状態に保ちます。
- **マウスを乗せるだけで数字** — ゲージにマウスを乗せると、`Claude : 5% / 50%`(5 時間 / 週間)のようにサービスごとに 1 行ずつ表示されます。
- **ステータス画面** — サービスごとの 5 時間 · 週間の使用率バーと、それぞれのリセットまでの残り時間。
- **7 日間の使用記録** — 1 日 1 本のバーで、週間使用率とその日に使った分を表示します。
- **タスクバーのテーマに合わせる** — ライトのタスクバーではゲージの後ろに黒い LED パネルを敷き、ダークではリングだけを表示します。テーマを切り替えるとすぐに反映されます。
- **使っているサービスだけ表示** — ログインしているサービスだけ円を描きます。Codex だけを使っているなら、Codex の円ひとつだけです。
- **起動時に実行** — 右クリックメニューでオン・オフします。インストール版はインストール時にオンになります。
- **22 言語** — Windows の表示言語に従います。

## 使い方

### はじめて使う

1. **Claude Code** か **Codex** にログインしていることを確認します。Aseul はこのログインを使って使用率を読み取ります(下の「動作環境」を参照)。
2. Aseul を起動します。少しすると、タスクバーの通知領域の左に**円形ゲージ**が現れます。
3. ゲージを見ます。外側のリングが週間、内側のリングが 5 時間の使用率です。リングが満ちているほど、赤に近いほど、残りが少ないということです。
4. 正確な数字を知りたいときは、ゲージに**マウスを乗せる**か、ゲージを**クリック**してステータス画面を開きます。
5. ステータス画面は閉じるボタンか **Esc** で閉じます。ゲージは残って更新を続けます。

### 画面構成

**タスクバーのゲージ**

| 要素 | 意味 |
|---|---|
| 左の円 / 右の円 | Claude / Codex(ログインしているサービスのみ) |
| 外側のリング | 週間使用率 |
| 内側のリング | 5 時間使用率 |
| リングの色 | 0–20 % 緑、20–40 % 黄緑、40–60 % 黄、60–80 % オレンジ、80–100 % 赤 |
| マウスを乗せる | サービスごとに `5 時間 % / 週間 %` |
| クリック | ステータス画面を開く |
| 右クリック | メニュー(下の表) |

**右クリックメニュー**

| メニュー | 動作 |
|---|---|
| **ステータス画面を開く** | ステータス画面を開きます — ゲージをクリックするのと同じです |
| **起動時に実行**(チェック) | Windows にログインしたときに自動で起動 |
| **作者 Kilho Oh** | Web サイトを開く |
| **終了** | 「本当に終了しますか？」と確認して終了します |

**ステータス画面**

| 要素 | 意味 |
|---|---|
| サービス名 | Claude、Codex |
| **5時間** · **週間** バー | 使用率 — ゲージと同じ色で、満ちた分だけ濃く |
| % | 現在の使用率 |
| **…後にリセット** | その上限が 0 に戻るまでの残り時間 |
| 7 日間グラフ | サービスの項目にマウスを乗せると、その場所に表示されます |

### こんなときは

**長い作業を任せる前に残りを確認したいとき**
ゲージにマウスを乗せると、`Claude : 35% / 72%` のように 5 時間 / 週間の使用率がすぐにわかります。週間が赤の区間に近ければ、大きな作業はリセット後に回すといった計画が立てられます。

**上限がいつ解除されるか知りたいとき**
ゲージをクリックしてステータス画面を開きます。5時間 · 週間のバーの右に **2日21時間後にリセット** のように残り時間が表示されます。

**今週どの日にたくさん使ったか見たいとき**
ステータス画面でサービスの項目(Claude または Codex)にマウスを乗せると、過去 7 日間のグラフが表示されます。1 日 1 本のバーで、いちばん右が今日です。バーの高さはその日の週間使用率、上の濃い部分はその日に増えた分です。バーにマウスを乗せると、`10/15(木) · 56% (+12%)` のように日付、週間使用率、その日に使った分が表示されます。

**Claude か Codex のどちらかだけを使っているとき**
設定は何もいりません。ログインしているサービスだけがゲージに円を描き、ステータス画面にもそのサービスだけが表示されます。

**明るい(ライト)タスクバーを使っているとき**
ゲージの後ろに黒い LED パネルが敷かれ、リングの色がくっきり見えます。ダークに切り替えるとパネルが消え、リングだけが残ります。タスクバーのテーマを切り替えるとすぐに反映されます。

**タスクバーのサイズを変えたとき**
小さいタスクバーボタンや 2 段のタスクバーなどで高さが変わると、ゲージもすぐに合わせて描き直されます。円はトレイアイコンと同じ大きさなので、高 DPI のモニターでもくっきり表示されます。

**パソコンを起動するたびにゲージを表示したいとき**
ゲージを右クリック → **起動時に実行** にチェックを入れます。インストール版はインストール時にすでにオンになっています。オフにするにはもう一度クリックしてチェックを外します。

**Claude Code や Codex に再ログインしたとき**
Aseul 側ですることはありません。次の確認で新しい値を読み取り、ゲージはそのまま続きます。それまでステータス画面には最後に受け取った値が薄く表示されます。

**ログインする前に起動したとき**
Claude Code と Codex のどちらにもログインしていない場合、「ログインしているAIがありません。」と表示して終了します。どちらかにログインしてから、もう一度起動してください。

**ステータス画面をもう一度見つけたいとき**
ステータス画面はタスクバーに専用のボタンを作りません。ゲージをクリックすると、ゲージがあるモニターの中央に開き、すでに開いていれば前面に出てきます。Aseul をもう一度起動しても、2 つ目は起動せずステータス画面が開きます。

**Aseul を完全に終了するとき**
ゲージを右クリック → **終了** → **はい**。ステータス画面を閉じるだけでは終了せず、ゲージは残ります。

## 設定

設定画面はありません。変えられるのは右クリックメニューの **起動時に実行** ひとつだけで、ほかは自動的に従います。

| 項目 | 従うもの |
|---|---|
| 起動時に実行 | インストール版はオン、ポータブル版はオフ — 右クリックメニューで変更 |
| 表示するサービス | ログインしているサービス(Claude、Codex) |
| ゲージの見た目 | タスクバーのライト / ダークテーマ |
| ゲージの大きさ | トレイアイコンの大きさ(タスクバーの拡大率) |
| ステータス画面 | 常にダーク |
| 表示言語 | Windows の表示言語(22 言語、それ以外は英語) |

## 動作環境

- Windows 10 · Windows 11 (64 ビット)
- **Claude Code** または **Codex** にログインしている必要があります。
  - Claude: Claude アカウントで Claude Code にログイン
  - Codex: ChatGPT アカウントで Codex にログイン(API キーでのログインには使用率がないため表示されません)
- 使用率を取得するためにインターネット接続が必要です。
- 別途ランタイムは不要です。インストール版はインストール時のみ管理者権限を使います。

## アップデート

Aseul は自動的にはアップデート**しません**。起動時に新バージョンの有無を確認して案内画面を表示し、**[はい]** を押すとダウンロードページが開いてプログラムが終了します。新バージョンは内部検証の後に手動で配布され、[Aseul ページ](https://kilho.net/aseul)で告知されます。[アップデートポリシー](https://en.kilho.net/archives/notice/2940)をご覧ください。
